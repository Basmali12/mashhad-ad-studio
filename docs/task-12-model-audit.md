## Fresh verification and dependency finding

All sixteen unique Hugging Face repository/revision pairs below returned exactly their pinned `sha` from the public `/api/models/{repo}/revision/{revision}` endpoint. All seven official source commits returned the exact requested SHA from GitHub's commit API. The four publisher-linked Hunyuan Diffusers variant repositories are distinct from Tencent's original-format repository; that distinction is intentional and must remain visible in operational provenance.

Official PyPI JSON was fetched for direct exact package pins in all twelve CPU/GPU requirement files. Active direct dependency constraints were compared for Linux x86_64, Python 3.12, and Python 3.10 for LatentSync. The audit found an actual resolver conflict: `tokenizers==0.23.1` requires `huggingface-hub>=0.16.4,<2.0`, while the four original image/video GPU locks pinned Hub 2.4.0. This was reported to the coordinating agent. The coordinating agent changed all eight corresponding CPU/GPU locks to **Hub 1.32.0**, which exists on PyPI and lies in the intersection with `diffusers==0.42.1` (`>=1.32,<3`) and `transformers==5.22.1` (`>=1.31,<3`). Current four GPU files were reread and contain 1.32.0; the coordinating agent also added three offline dependency-constraint checks. No other direct pinned conflict was found in the metadata comparison. This does not prove the entire transitive resolver, Linux/CUDA wheel installation, import ABI, native build or inference.

Primary metadata: [tokenizers 0.23.1](https://pypi.org/pypi/tokenizers/0.23.1/json), [Hub 1.32.0](https://pypi.org/pypi/huggingface-hub/1.32.0/json), [Diffusers 0.42.1](https://pypi.org/pypi/diffusers/0.42.1/json), [Transformers 5.22.1](https://pypi.org/pypi/transformers/5.22.1/json). Its L40S Ada profile avoids assuming that the older CUDA121 wheel supports every newer GPU architecture.

All locks pin direct dependencies but are **not** complete transitive, platform-specific wheel-hash lockfiles. Source/git and binary ABI/native extensions, FFmpeg availability and codec behavior require a real isolated image build. Current mocked pipeline factories do not import/download actual model components. An installed Modal SDK definition registering locally proves SDK shape only, not successful authentication, capacity allocation, deployed image imports or model readiness.

## Licence and release blockers

- **FLUX/Qwen/Wan:** pinned model metadata declares Apache2.0. Keep publisher attribution/licence notices and component notices. Apache permission does not clear a user's image, trademark, face or third-party content rights.
- **Habibi:** the repository-level HF card is CC-BY-NC-SA4.0, but the [pinned official README licence section](https://github.com/SWivid/Habibi-TTS/blob/3b4d793481f1a8e686a2229c6d7946c5d9f6b8c0/README.md#license) explicitly separates MIT code and Apache2 specialized ALG/EGY/IRQ/MAR/MSA from NC Unified/SAU/UAE. The manifest selects only permittedspecializedIRQ/EGY/MSA. Do not generalize this exception to any checkpoint from the same repository. Reference-speaker consent and licence remain independently necessary.
- **Audar:** the [pinned model licence](https://huggingface.co/audarai/Audar-TTS-V1-Flash/blob/addf2d80538edab4de2103843678825bc11ddce1/LICENSE) is AudarAI Open v1.0, not Apache2. It explicitly permits paid hosted/commercial services with no revenue/user cap, subject to its notices, redistribution, branding, third-party and lawful-use conditions. NeuCodec's auto gate must be accepted by the intended account using its existing account-owned HFreadsecret. Publicmetadata availability does not establish fileaccess; no gated download was attempted or bypassed.
- **Hunyuan:** the [pinned Tencent licence](https://github.com/Tencent-Hunyuan/HunyuanVideo-1.5/blob/60783e704160023913bee78f0b47036d393d4dfa/LICENSE) explicitly excludesEU/UK/SouthKorea and restricts use/distribution/output there. It adds Tencent permission requirements above100millionMAU at release, notices/branding and AUP obligations. A globally accessible customer service needs an actual territory/compliance decision before enablement; an admin confirmation does not override licence terms.
- **LatentSync:** Apache2 source does not relicense OpenRAIL++ modelweights or InsightFace pretrainedweights. [InsightFace's official policy](https://github.com/deepinsight/insightface#license) makes codeMIT but pretrainedmodels noncommercialresearch-only, including manualGitHubdownloads. Current buffalo_m therefore remains a **commercial-release blocker**, unless an actual appropriate licencegrant is obtained or a genuinely compatible licensedreplacement is implemented/tested. A checkbox or opaque rightsEvidence ID cannot itself create rights. `commercialReady:false` is accurate. Facebindings and perframefacecount prevent wrong-personselection; they do not remove licence restrictions or certify lip quality.
