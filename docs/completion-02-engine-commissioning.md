Date: 2026-10-31. Repository `Basmali12/mashhad-ad-studio`, branch `codex/ltx-film-engine-integration`. Local-only implementation; no commit, push, production deployment, paid API, GPU, weight download or backup. No subsequent completion task started.

## Implemented contracts

- Existing encrypted account linking and token verification remain unchanged. `EngineDefinitions` reuses the current administration tabs, RTL classes and layouts; pinned runtime defaults are suggested only for new definitions. Existing prices and resources are not silently changed. Technical controls remain in details.
- Registry preparation retains the exact per-account/per-model/per-definition Volume namespace and pinned SHA/size verification. Quotes list missing files and their size/cost; correct files are not requested again. A completed CPU preparation is verified on status even when the immediate provider response already confirms stop. No status operation resubmits preparation. Byte progress comes from actual recorded values.
- `admin.engine.test.project` creates a private admin-owned test plan without inference. FLUX can start from a bounded prompt. Qwen/Wan/Hunyuan image animation needs legitimate reviewed image inputs; speech requires an approved owned voice profile/consented PCM reference. LatentSync needs actual prepared audio/video/alignment/face inputs and valid rights. Missing input yields blockers, never a fake successful sample. IDs required for chaining are visible in advanced results.
- `admin.engine.test.quote/execute/status/review/stop` handle an independently priced native inference test, immutable intent ID, actual output verification, human review and confirmed resource stop. Request-specific follow handles a lost execute response; an old stopped test cannot clear uncertainty for a newer unknown command. A stale stop cannot stop a replacement test. Process recovery never replays a paid request.
- `admin.engine.approve/publish/unpublish` are separate actions. Publication is bound to current engine revision, account credentials/workspace digest, resource settings, manifest, software/dependency fingerprints, licence policy and reviewed successful test. Missing or corrupt files, changed credentials/settings, unreviewed newer tests or revoked rights remove effective admission. Weights alone do not certify inference.
- The real future test runner reuses the installed production adapters, registry start/stop and original image/audio/video asset verification. Tests run in isolated administrative projects, not customer film stages; no customer credit or financial record is fabricated. Published states cannot be supplied as HTTP evidence. Admin sample projects are excluded from ordinary customer production history.
- Test media uses short-lived owner-authorized signed tickets at `/api/film-engine-test/<opaque-id>`, with verified bytes, range serving, MIME allowlist and no-store headers. Gateway rejects arbitrary origins, paths and extra query fields. No credentials or internal file path is sent to the browser.
- Effective publication materializes a generic slot in the existing customer catalog at the saved tariff and records the default Production model binding if none exists. Unpublishing closes new bookings and removes that default; existing historical records and running rental prices remain unchanged. Current proof is checked at catalog/quote/dispatch, not only at publication time.
- A registry rental bridge implements the existing quote/start/job-status/stop contract for generic engines. Existing wallet lots, admission minimum, microUSD arithmetic, one-rental-per-customer checks and metering remain authoritative. Startup/idle time continues until confirmed stop. Runtime/job/rental mirrors count one lease, not multiple leases; tests cover two declared slots and separate owners. Owned active rentals make the same Production engine busy rather than allocating another paid run or charging twice. No implicit paid fallback.
- Existing account emergency stop also covers generic preparations/tests/runtimes. Generic definitions cannot be mutated through retired slot setup/publication routes. Old account-level LTX commissioning/test/transfer links were removed from the primary UI, while encrypted account controls, capacity, manual billing, locks, customer credits and history remain.
