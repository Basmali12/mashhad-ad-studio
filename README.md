# مشهد — الجدولة وإدارة المحركات

مشروع مشهد الحالي بواجهة React/TypeScript/Vite عربية RTL، مع تسجيل الدخول والجدولة والاشتراكات والملفات والمحفظة ولوحة الإدارة. المستودع الحالي `Basmali12/mashhad-ad-studio` والفرع `codex/ltx-film-engine-integration`.

## حالة محرك الأفلام

أُلغي محرك LTX-2.5 ومسارات DFR/Conv وملفات استدلاله في المهمة الأولى. لا يوجد بديل مفعّل في هذه المرحلة. طلب إنتاج جديد يجب أن يرفض بأمان قبل بناء صورة أو تجهيز أوزان أو بدء GPU؛ لا نجاح وهمي أو إعادة تفعيل تلقائية.

تبقى إدارة حسابات Modal والتشفير وفحص الاتصال وإدارة التخزين والمراقبة والإيقاف والأسعار والمحفظة وصلاحيات الإدارة. تجهيز نموذج جديد يتطلب تعريفاً معتمداً للملفات والتبعيات؛ حقول الحساب وحدها لا تجيز تنزيل نموذج أو تنفيذ عملية مدفوعة.

حذف الكود محلياً لا يثبت حذف موارد الخادم أو Modal. حالة التنفيذ الفعلية وتفاصيل المهام المسجلة في [docs/task-01-retirement.md](docs/task-01-retirement.md).

## التشغيل والفحوص المحلية

```powershell
npm ci
npm run dev
npm run typecheck
npm run lint
npm test
npm run film:engine:check
npm run film:gateway:check
npm run build
npm run build:admin
```

المعاينة محلية فقط على العنوان الذي يعرضه Vite. البناء والفحوص لا ينشران الموقع ولا ينشئان موارد سحابية.

## حدود الخدمات

- واجهة الزبون والإدارة لهما بناءان منفصلان؛ الصلاحيات تتحقق في الخادم.
- أجزاء مشهد الأصلية للجدولة تحتفظ بتكامل Clerk/Convex والتخزين والنشر الخاص بها.
- `services/film-gateway` يربط الهوية الموثوقة بخدمة الأفلام.
- `services/film-engine` يحفظ إدارة الحسابات والمحفظة والمشاريع والملفات في الخدمة المستضافة ذاتياً وقاعدة بياناتها.
- أوزان النماذج ليست داخل PostgreSQL؛ مفاتيح Modal لا تصل إلى المتصفح بعد حفظها.
- لا تحذف المحادثات أو ملفات المستخدمين أو سجلات الدفع ضمن إزالة محرك الاستدلال.
